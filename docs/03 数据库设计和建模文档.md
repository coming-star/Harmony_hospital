# 东软云医院挂号预约系统 · 数据库设计和建模文档

> 技术栈：SpringBoot + MyBatis-Plus + MySQL 8 + Redis（缓存/验证码）+ RocketMQ（超时释放）
> 设计原则：单院区精简、逻辑删除不破坏唯一索引、支付预占防超卖、先选时间后选医生、易实现优先

## 一、核心抽象

| 概念 | 是什么 | 来源 | 关键点 |
|---|---|---|---|
| **user 用户** | 登录账户，操作软件的人 | 手机注册自动生成 | 所有手机注册都是 `role=0` 普通用户；管理员 `role=9`。医生在 APP 注册也是普通用户，与执业身份不冲突 |
| **patient 就诊人** | 实名就医档案，被挂号的人 | 身份证唯一 | 必须有身份证；一个用户可绑多个就诊人（本人/父亲/母亲）。挂号记 `patient_id`，看诊核验就诊人本人身份证 |
| **doctor 医生** | 医院出诊人 | 管理员按工号录入 | `doctor_code` 工号；不是用户注册出来的 |

**易混淆点**：
- **用户 ≠ 就诊人**：用户是操作人，就诊人是实际就医人。张三帮父亲挂号 → `appointment.user_id=张三, patient_id=父亲`，看诊刷父亲身份证。
- **职称 ≠ 号别**：`doctor_title`（职称）仅展示；`schedule.register_type`（号别）决定费用。同一医生可同时有"专家号排班（贵）"和"普通号排班（便宜）"。

**关键约定**：
- 所有表含 `id / deleted / create_time / update_time`；金额 `decimal(10,2)`；状态 `tinyint`；
- `deleted` 用 **bigint**（0 未删，软删置 id），唯一键用 `(业务键, deleted)` 组合，软删后业务键可复用；
- 系统用户表名为 `user`（Entity `User`），MySQL 中 `user` 非保留字，建表/查询用反引号 `` `user` `` 规避与 `USER()` 函数、`mysql.user` 系统表混淆；
- 号源粒度只到**时段（上午/下午）**，不精确到具体时间点，无 `schedule_slot` 表。

## 二、业务流程

1. **预约**：App → 选一级科室 → 二级科室 → 选日期+时段(上午/下午) → 显示有号医生+剩余名额+号别筛选 → 选医生 → **下单预占号源** → 支付 → 成功 → "我的"查看订单。
2. **AI 管家**：登录后 → 推荐可约医生 / 导诊 / 代预约（复用同一下单+支付流程，不新增表）。
3. **注册/登录**：手机验证码注册 → 自动建 `user` + 本人 `patient` + 本人绑定。

## 三、实体关系（ER）

```
department(两级, parent_id) 1:N doctor(工号录入)
doctor 1:N schedule(上午/下午+号别+号源)
user 1:N user_patient N:1 patient(可多人)
patient 1:N appointment 1:1 pay_order N:1 refund_log
schedule 1:N appointment
后台操作 → audit_log ；枚举 → dict_type / dict_item
```

## 五、关键业务规则

### 5.1 号源防超卖（下单预占 + 支付扣减）
```sql
-- 下单(选医生提交): 事务内条件更新, 有可用号才预占
UPDATE schedule SET locked_num = locked_num + 1, version = version + 1
 WHERE id = ? AND (remain_num - locked_num) > 0 AND deleted = 0;
-- 支付成功: 扣减剩余, 释放预占
UPDATE schedule SET remain_num = remain_num - 1, locked_num = locked_num - 1, version = version + 1
 WHERE id = ? AND deleted = 0;
-- 超时未付 / 取消未付: 仅释放预占
UPDATE schedule SET locked_num = locked_num - 1, version = version + 1
 WHERE id = ? AND locked_num > 0 AND deleted = 0;
-- 取消已付订单: 返还剩余号源
UPDATE schedule SET remain_num = remain_num + 1, version = version + 1
 WHERE id = ? AND deleted = 0;
```
释放号源后若 `(remain_num - locked_num) > 0` 且原 `schedule_status=1(已满)`，同步恢复为 0(可约)。

### 5.2 逻辑删除不破坏唯一索引
`deleted bigint`；唯一键 `(业务键, deleted)`；软删 `UPDATE t SET deleted = id WHERE id = ? AND deleted = 0`，旧业务键可重用。

### 5.3 核心查询：先选时间后选医生（高频）
```sql
SELECT d.id doctor_id, d.doctor_name, d.doctor_title, d.doctor_avatar,
       s.id schedule_id, s.remain_num, s.register_price, s.register_type, s.work_date, s.time_slot
FROM schedule s JOIN doctor d ON d.id = s.doctor_id
WHERE s.dept_id = ?            -- 二级科室
  AND s.work_date = ?          -- 选的日期
  AND s.time_slot = ?          -- 上午/下午
  AND s.register_type = ?      -- 号别筛选(全部则去掉此行)
  AND (s.remain_num - s.locked_num) > 0
  AND s.schedule_status = 0 AND s.deleted = 0
ORDER BY s.register_price;
```

### 5.4 用户查"我的预约"
`SELECT ... FROM appointment WHERE user_id = ? AND deleted = 0 ORDER BY create_time DESC`，按 `status` 分类，配合 Token 鉴权做数据隔离。

### 5.5 防重复挂号（服务层规则）
```sql
SELECT COUNT(*) FROM appointment
 WHERE patient_id = ? AND schedule_id = ?
   AND status IN (0, 1) AND deleted = 0;
-- 结果 > 0 → 拒绝再次预约
```

### 5.6 排队号 queue_no 生成
支付成功时按排班顺序生成：`queue_no = 该排班当前已支付且未取消的订单数 + 1`（Redis `INCR schedule:queue:{scheduleId}` 或事务内 COUNT 实现）。

## 七、示例数据（张三给父亲挂专家号，含支付）

**department**：`(1, NK, 内科, 0)`、`(2, XXG, 心血管内科, 1)`

**doctor**（管理员工号录入）：`(1, 2, D001, 王明, 主任医师)`

**user**（含医生本人注册也是普通用户）：`(1, 13800000001, 0, 张三)`、`(9, admin01, 9, 管理员)`

**patient**（可多人）：`(1, 张三, ...0001, 本人)`、`(2, 李四海, ...543X, 父亲)`、`(3, 王秀英, ...8888, 母亲)`

**user_patient**：`(1,1,1,本人,1)`、`(2,1,2,父亲,0)`、`(3,1,3,母亲,0)`

**schedule**（专家号）：`(1, 1, 2, 2026-01-16, 上午, 1, total=20, remain=19, locked=0, price=50.00)`

**appointment**（支付成功后）：`(GH2026011500001, user_id=1张三操作, patient_id=2父亲, schedule_id=1, price=50, pay_status=1, status=1已预约)`

**pay_order**：`(P2026011500001, GH2026011500001, user_id=1, 50.00, 微信, 成功, WX2026ABC)`

> 看诊核验的是**父亲李四海的身份证**；医生王明若要在 APP 挂号，需另用手机注册普通 `user` + 本人 `patient`，与 `doctor` 记录独立不冲突。

**数据流转**：张三注册→自动建 user+patient(本人)+绑定 → 绑父亲/母亲 → 选内科→心血管内科→2026-01-16上午→筛专家号 → 查 schedule JOIN doctor 得王医生(remain=20) → 下单(appointment 待支付, locked 0→1) → 支付¥50(pay_order 成功, locked 1→0, remain 20→19, status=1已预约) → "我的"页看到已预约订单。取消则 status=2，已付→refund_log 退费，remain 19→20；超时未付→status=2(原因=超时未支付)，locked 释放。
