# 东软云医院挂号预约系统 · 接口文档

> 在线调试：Knife4j（开发环境 `/doc.html`）

## 一、通用规范

### 1.1 基本信息

| 项 | 内容 |
|---|---|
| Base URL | 开发环境 `http://localhost:8080`；鸿蒙模拟器 `http://10.0.2.2:8080` |
| 数据格式 | 请求/响应均为 JSON（`application/json;charset=UTF-8`） |
| 时间格式 | `yyyy-MM-dd HH:mm:ss`；日期 `yyyy-MM-dd` |

### 1.2 统一返回结构 `Result`

```json
{ "code": 200, "message": "成功", "data": {} }
```

| code | 含义 |
|---|---|
| 200 | 成功 |
| 400 | 参数错误 / 业务校验失败（message 说明原因） |
| 401 | 未登录 / token 失效或过期 |
| 403 | 无权限（非管理员访问管理接口） |
| 500 | 系统异常 |

业务失败示例（号源已满）：`{"code": 400, "message": "该排班号源已满，请选择其他医生或时间", "data": null}`

### 1.3 鉴权方式

- 除「公开接口」外，请求头需携带：`Authorization: Bearer <token>`；
- 无 token / token 过期 → 返回 `401`。

### 1.4 分页参数（列表接口通用）

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| pageNum | int | 是 | 页码，从 1 开始 |
| pageSize | int | 是 | 每页条数 |

分页响应 `data`：`{ "records": [...], "total": 100, "size": 10, "current": 1 }`。

## 二、认证模块（Auth）

### 2.1 发送短信验证码

- **接口**：`POST /api/auth/sms-code`；**鉴权**：公开
- **请求**：`phone`（string，必填）
- **响应**：`{"code":200,"message":"验证码已发送","data":null}`
- **说明**：开发期用模拟验证码 `123456` 或 Redis 生成码（生产接短信通道）。

### 2.2 手机验证码登录（未注册自动注册）

- **接口**：`POST /api/auth/login/sms`；**鉴权**：公开
- **请求**：`phone`（string，必填）、`code`（string，必填）
- **响应**：

```json
{
  "code": 200, "message": "登录成功",
  "data": { "token": "eyJhbGciOi...", "userId": 1, "nickName": "张三", "role": 0, "isNewUser": false }
}
```

- **说明**：未注册自动创建 `user` + 默认"本人"`patient` + 绑定。

### 2.3 管理员账号密码登录

- **接口**：`POST /api/auth/login/password`；**鉴权**：公开
- **请求**：`username`、`password`（BCrypt 校验）
- **响应**：同 2.2（role=9）。

### 2.4 退出登录

- **接口**：`POST /api/auth/logout`；**鉴权**：需登录

### 2.5 当前用户信息

- **接口**：`GET /api/user/info`；**鉴权**：需登录
- **响应** `data`：`{ "userId":1, "nickName":"张三", "phone":"13800000001", "avatar":"", "role":0 }`

## 五、排班模块（Schedule）⭐ 核心查询

### 5.1 可约医生查询（先选时间后选医生）

- **接口**：`GET /api/schedule/available?deptId=2&workDate=2026-09-05&timeSlot=上午&registerType=`
- **鉴权**：公开
- **参数**：

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| deptId | long | 是 | 二级科室 id |
| workDate | string | 是 | 出诊日期 `yyyy-MM-dd` |
| timeSlot | string | 是 | 时段：上午 / 下午 |
| registerType | int | 否 | 号别：0 普通 / 1 专家 / 2 急诊；不传=全部 |

- **响应** `data`：

```json
[
  {
    "scheduleId": 1001, "doctorId": 1, "doctorName": "王明", "doctorTitle": "主任医师",
    "registerType": 1, "registerTypeName": "专家", "registerPrice": 50.00,
    "remainNum": 19, "timeSlot": "上午"
  }
]
```

- **说明**：仅返回 `(remain_num - locked_num) > 0` 且可约的排班；名额为 0 的医生不可选。

### 5.2 排班管理（管理端）

| 功能 | 接口 | 鉴权 |
|---|---|---|
| 排班分页 | `GET /api/admin/schedule/list?doctorId=&workDate=&pageNum=&pageSize=` | 管理员 |
| 新增排班 | `POST /api/admin/schedule`（doctorId/workDate/timeSlot/registerType/totalNum/registerPrice） | 管理员 |
| 编辑排班 | `PUT /api/admin/schedule/{id}` | 管理员 |
| 删除排班 | `DELETE /api/admin/schedule/{id}` | 管理员（仅未被预约可删） |

## 七、预约 & 支付模块（Appointment）⭐ 核心

### 7.1 创建预约（下单预占）

- **接口**：`POST /api/appointment`；**鉴权**：需登录
- **请求**：`scheduleId`（long）、`patientId`（long，须为当前用户绑定）
- **响应** `data`：

```json
{
  "orderNo": "GH202609050001", "registerPrice": 50.00, "registerTypeName": "专家",
  "status": 0, "expireMinutes": 15, "payNeed": true
}
```

- **说明**：校验就诊人归属 + 防重复挂号 → 预占号源（`locked_num+1`）→ 生成待支付订单 → 发送超时延迟消息。号源已满 / 重复挂号 → 400。

### 7.2 支付（模拟支付）

- **接口**：`POST /api/appointment/pay`；**鉴权**：需登录
- **请求**：`orderNo`（string）、`payType`（int，1-微信 2-支付宝）
- **响应**：`{"code":200,"message":"支付成功","data":{"queueNo":1,"status":1}}`
- **说明**：开发期模拟支付；生产对接微信/支付宝，回调幂等处理。

### 7.3 我的预约列表（按状态）

- **接口**：`GET /api/appointment/my?status=&pageNum=1&pageSize=10`；**鉴权**：需登录
- **参数**：status 0 待支付 / 1 已预约 / 2 已取消 / 3 已完成（不传=全部）
- **响应** `data.records`：

```json
[
  {
    "orderNo": "GH202609050001", "deptName": "心血管内科", "doctorName": "王明",
    "patientName": "李四海", "workDate": "2026-09-05", "timeSlot": "上午",
    "registerTypeName": "专家", "registerPrice": 50.00,
    "status": 1, "statusName": "已预约", "payStatus": 1, "queueNo": 1
  }
]
```

### 7.4 预约详情

- **接口**：`GET /api/appointment/{orderNo}`；**鉴权**：需登录（仅本人订单）

### 7.5 取消预约

- **接口**：`POST /api/appointment/cancel`；**鉴权**：需登录
- **请求**：`{"orderNo":"GH202609050001","reason":"临时有事"}`
- **说明**：待支付/已预约可取消；已付自动退费并返还号源。

## 八、AI 管家模块（AI Assistant）

### 8.1 AI 对话

- **接口**：`POST /api/ai/chat`；**鉴权**：需登录
- **请求**：`content`（string，用户对话内容）
- **说明**：三类对话：①推荐可约医生（时间+科室）；②症状导诊（挂什么科）；③代预约（复用 7.1 下单，返回待支付订单并提示支付按钮）。
- **响应** `data`（按意图不同）：

```json
// 意图①推荐医生
{ "intent": "RECOMMEND_DOCTOR",
  "reply": "心血管内科 2026-09-05 上午 专家号可约医生：王明（主任医师，¥50，余19）...",
  "doctors": [ {...} ] }

// 意图②导诊
{ "intent": "TRIAGE", "reply": "根据您的症状描述，建议前往心血管内科就诊..." }

// 意图③代预约
{ "intent": "BOOK",
  "reply": "已为您生成心血管内科 2026-09-05 上午 普通号订单，请点击支付",
  "order": { "orderNo": "GH...", "registerPrice": 30.00, "status": 0, "payNeed": true } }
```

## 九、管理端接口（Admin）

### 9.1 仪表盘统计

- **接口**：`GET /api/admin/dashboard`；**鉴权**：管理员
- **响应** `data`：`{ "todayAppointment":120, "doctorCount":45, "departmentCount":12, "userCount":3200, "appointmentTrend":[...], "latestAppointments":[...] }`

### 9.2 预约订单管理

| 功能 | 接口 | 鉴权 |
|---|---|---|
| 预约列表（状态筛选/分页） | `GET /api/admin/appointment/list?status=&pageNum=&pageSize=` | 管理员 |

### 9.4 科室 / 医生 / 排班管理

见第三、四、五章 `/api/admin/department`、`/api/admin/doctor`、`/api/admin/schedule` 系列接口。

## 十、错误码场景

| code | 场景示例 |
|---|---|
| 400 | 参数缺失/格式错误；号源已满；重复挂号；就诊人非本人绑定；科室存在子科室/医生禁删；排班已被预约禁删 |
| 401 | 未携带 token / token 过期 / 登录态失效 |
| 403 | 普通用户访问管理端接口 |
| 500 | 系统异常 |
